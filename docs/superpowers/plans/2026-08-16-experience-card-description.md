# Experience Card Description Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every collapsed work card an explicit one-line description, show description plus responsibility details when expanded, increase fixed-card height, and correct the requested Education data.

**Architecture:** Move each short role summary into a `description` front-matter field and leave only responsibility bullets in the markdown body. Render `job.description` independently in the summary and expanded panel, retain the existing accordion JavaScript, and use the shared summary-height custom property so card, timeline dot, and connector geometry continue to move together.

**Tech Stack:** Jekyll collections and Liquid, Markdown/YAML front matter, SCSS, Ruby rendered-page integration tests, Node JavaScript tests, in-app browser verification.

## Global Constraints

- The collapsed summary reads `job.description` directly and never truncates `job.content`.
- The expanded panel renders the description followed by the markdown responsibility list.
- `--experience-summary-height` must be `148px`.
- Desktop and mobile summaries show one description line with ellipsis rather than hiding it.
- Existing accordion JavaScript and accessible state behavior remain unchanged.
- Master’s details contain `GPA 3.88`.
- Bachelor’s details retain `GPA 3.95` and remove `IEEE Student Branch`.
- The hidden AIRTIST entry receives the same markdown schema.
- Leave the pre-existing untracked `.superpowers/` directory untouched.
